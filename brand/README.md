# Brand assets

- `logo` — официальный логотип из вложения и отдельный marketplace-вариант с Яндекс Диска;
- `products` — 21 оригинальная JPG-карточка для трёх товарных серий;
- `illustrations` — место для будущих самостоятельных иллюстраций;
- `photos` — место для будущей отдельной фотосъёмки;
- `misc` — резерв для прочих web-assets.

Файлы не перекодировались и не ретушировались. Серии товаров получили короткие ASCII-пути, удобные для импорта в коде.
